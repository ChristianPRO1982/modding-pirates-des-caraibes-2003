# B1.1 - Les Fils de l'Ombre d'Inty - Items 1

## Decision retenue

Pour `G1.1`, le premier tour de collecte repose simplement sur les objets `indian1` a `indian16`.

Cela signifie:

- le joueur doit reunir un exemplaire de chaque objet `indian1`, `indian2`, `indian3`, ..., jusqu'a `indian16`;
- ces seize objets constituent le premier groupe d'objets a rapporter a Silehard;
- il ne faut pas utiliser ici `idol` ni `icollection`.

## Deuxieme tour

Pour le deuxieme tour de `G1.1`, nous creerons de nouveaux items dedies a la statue.

Regle retenue:

- la statue complete reprendra la texture de `idol`;
- les elements separes de la statue reprendront la texture de `icollection`.

A ce stade, ce document ne fixe rien d'autre.
